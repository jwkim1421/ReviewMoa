# 리뷰모아 수집 도우미

1. Chrome 또는 Edge에서 확장 프로그램 관리 화면을 연다.
2. 개발자 모드를 켠다.
3. `압축해제된 확장 프로그램을 로드`하고 이 `extension` 폴더를 선택한다.
4. 리뷰모아 웹에서 상품 URL을 입력한다.

확장 코드를 업데이트한 경우 확장 관리 화면에서 새로고침 버튼을 눌러야 변경 내용이
반영된다. 수집기는 리뷰 탭, 최신순, 5점부터 1점까지의 필터, 다음 페이지와 더보기를
순서대로 시도한다. 자동 탐색이 실패하면 해당 쇼핑몰에서 리뷰 탭이나 필터를 직접
연 뒤 확장 팝업의 `현재 페이지에서 다시 확인`을 누른다.

로그인과 CAPTCHA는 쇼핑몰 화면에서 사용자가 직접 처리한다. 확장 프로그램은
비밀번호나 로그인 쿠키를 읽어 서버로 전송하지 않는다.
